# SEO Plan — Lux Tiles & Stones

Strategic SEO plan produced with the `seo-plan` skill (local-service template) plus our
Local SEO Playbook. Read in this order:

1. **[SEO-STRATEGY.md](./SEO-STRATEGY.md)** — discovery, positioning, content strategy,
   technical foundation, KPI targets, risks. Start here.
2. **[SITE-STRUCTURE.md](./SITE-STRUCTURE.md)** — URL hierarchy, content pillars,
   keyword→page map, internal linking, quality gates.
3. **[COMPETITOR-ANALYSIS.md](./COMPETITOR-ANALYSIS.md)** — LA tile/stone landscape,
   keyword gaps, E-E-A-T posture. (Estimates — verify with real tools before acting.)
4. **[CONTENT-CALENDAR.md](./CONTENT-CALENDAR.md)** — what to publish, when, to what gate.
5. **[IMPLEMENTATION-ROADMAP.md](./IMPLEMENTATION-ROADMAP.md)** — 4-phase action plan,
   separating build tasks from owner-side inputs.

> **New-site mode.** No live analytics or DataForSEO at time of writing, so all traffic /
> domain-authority / ranking numbers are **planning projections and rough estimates**,
> not measurements. Re-baseline once Search Console + GA4 have ~28 days of data, and
> replace competitor estimates with tool-measured figures.

**The two biggest levers are owner-side, not code:** real project photography, and a
Google Business Profile with genuine reviews. Never publish fabricated reviews, ratings,
credentials, or an address.
